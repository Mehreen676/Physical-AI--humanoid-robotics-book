# URDF & SDF for Simulation

## URDF
- Links + joints
- Visual vs collision geometry

## SDF
- More simulation-native
- World plugins + sensor definitions

## Best Practices
- Accurate mass/inertia
- Separate collision mesh (simple)
- Name joints cleanly for controllers
