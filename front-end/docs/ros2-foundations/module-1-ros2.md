# Module 1: The Robotic Nervous System – ROS 2

ROS 2 (Robot Operating System 2) is the middleware that connects perception, planning, and control inside a robot.

It acts as the **nervous system** of a humanoid robot.

---

## 🎯 What You Will Learn

- ROS 2 architecture
- Nodes, Topics, Services, Actions
- DDS communication layer
- Node lifecycle
- URDF basics
- How AI agents connect to robot controllers

---

## 🧠 Why ROS 2 Matters

Humanoid robots require:

- Real-time communication  
- Reliable execution  
- Modular design  
- Sensor integration  
- Scalable architecture  

ROS 2 provides all of this.

Without ROS 2, perception, planning, and motion cannot coordinate properly.

---

## 🏗 Architecture Overview

ROS 2 works using:

- **Nodes** (small programs)
- **Topics** (data streams)
- **Services** (request/response)
- **Actions** (long-running goals)
- **DDS** (communication backbone)

This allows robots to behave like distributed AI systems.

---

## 🤖 Example Humanoid Flow

User says:

> "Go to the kitchen"

System flow:

Voice → Whisper  
LLM → Plan steps  
ROS 2 Action → Navigate  
Motor Controller → Execute  

This entire pipeline runs through ROS 2.
